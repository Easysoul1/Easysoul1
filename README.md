# About Me

Hi, I'm **Adejumo Adedayo**, a **Full-Stack Software Engineer** focused on building modern, scalable web applications and solving real-world problems with software.

I work primarily with **TypeScript, JavaScript, React, Next.js, Angular, NestJS, Node.js, Django, and PostgreSQL**, with experience across both frontend and backend development.

I enjoy taking products from **idea to production** — designing interfaces, building reusable frontend architecture, integrating REST APIs, designing backend services, working with databases, implementing authentication and role-based access control, debugging complex issues, and deploying applications.

### What I Work With

- **Frontend:** React, Next.js, Angular, TypeScript, JavaScript, Tailwind CSS
- **Backend:** NestJS, Node.js, Express.js, Django
- **Database:** PostgreSQL, Prisma
- **Engineering:** REST APIs, API Integration, Authentication, RBAC, Debugging, Git, GitHub
- **Tools:** Vite, Docker, Postman, Figma

### What I'm Interested In

I'm particularly interested in **modern web engineering, developer tools, AI-powered products, scalable systems, and building software that solves meaningful problems**.

I also enjoy contributing to developer communities, mentoring others, participating in hackathons, and continuously learning new technologies.
